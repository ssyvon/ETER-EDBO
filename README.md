# ETER EDBO

Project figures, charts, plots, exported diagrams, and other generated image files must be saved directly under the repository-level `figures/` directory.

Do not use notebook-specific subdirectories for figures. Prefix figure filenames with the source notebook number, for example:

- `figures/01_eter_coverage_by_year.png`
- `figures/02_edbo_region_summary.png`
- `figures/03_model_comparison.png`
